# XNU build for husky

Builds xnu-12377 (iOS 26 era) on a macOS GitHub runner via
[blacktop/darwin-xnu-build](https://github.com/blacktop/darwin-xnu-build)
(DXB, pinned in `.github/workflows/xnu.yml`), applying `patches/` in order —
the same recipe `ios-sweet` uses, retargeted to iOS 26 and husky.

## Why a Mac / CI
XNU needs the Apple toolchain + KDK + SDK; DXB stages all of that on macOS.
There is no local Mac here, so the build runs on GitHub's macOS runners
(free minutes on a public repo). `tools/xnu-cc.py` (from ios-sweet) can
replay a single file's compile command locally against a downloaded build
tree, to check a patch without spending a CI run.

## Milestones
- **P1.0 — baseline:** build the stock `VMAPPLE` config of xnu-12377 with
  no patches. Proves DXB + xnu-12377 + the Xcode-26 toolchain work end to
  end before any husky code is involved.
- **P1.1 — HUSKY board:** `patches/0001-husky-machine-config.patch` adds a
  `HUSKY` machine config modeled on `VMAPPLE` (see
  `docs/superpowers/specs/2026-10-20-ios26-husky-port-design.md`): arm64e
  (keep PAC), `config_pmap_ppl`, `XNU_MONITOR`/`PMAP_CS`/`HAS_CTRR`/`HAS_KTRR`
  off, native GICv3, 16K pages.
- **P1.2 — architected PAC backend:** fill the empty key macros
  (`pac_asm.h`, `machine_routines_asm.s`, `machine_routines_apple.c`) with
  the architected `msr AP*Key*_EL1` writes validated in P0c.
- **P1.3 — console + early boot:** route XNU's console to the ramoops pmsg
  zone (per `shim/console.h`) and the shim loads the Mach-O + ADT.

Unlike sweet (Cortex-A76/A55, no PAC → plain arm64), husky has PAC and iOS
26 is arm64e-only, so we build **arm64e** and the PAC backend (P1.2) is new
work sweet never needed.

## Run
```sh
gh workflow run xnu.yml -R <you>/ios-husky                       # baseline (VMAPPLE)
gh workflow run xnu.yml -R <you>/ios-husky -f machine_config=HUSKY
gh run download <RUN_ID> -R <you>/ios-husky -n xnu-kernel -D xnu/out
```

`patches/` is generated by editing the DXB/cloned xnu tree and
`git diff`-ing (see `artifacts/xnu-12377`, a local shallow clone used only
to author and sanity-check patches — it is gitignored).
